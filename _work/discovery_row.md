# Discovery: Rest of World (Korea, Israel, India, Russia, Turkey, ME, SG, HK)
Agent sweep completed 2026-08-02. Korean terminology: 이동형 양팔로봇 ("mobile dual-arm robot", Rainbow's official term), 바퀴형/휠 기반 휴머노이드 ("wheeled humanoid"), 세미 휴머노이드 ("semi-humanoid").
