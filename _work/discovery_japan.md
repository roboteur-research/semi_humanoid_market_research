## Japanese terminology
- セミヒューマノイド "semi-humanoid" — actively used 2025-26 trade media (AGIRobots, Pudu D7); replacing older 上体型. GROWING/standard.
- 上体型 / 上半身型ヒューマノイド / 上半身人型ロボット "upper-body type humanoid" — older/technical (RT Sciurus17).
- 車輪型ヒューマノイド (also 車輪式/車輪移動型) "wheel-type humanoid" — standard trade-press term, esp. for Chinese imports.
- 双腕ロボット "dual-arm robot" — dominant industrial term (Yaskawa SDA, Kawasaki 双腕自律走行ロボット). No mobility implication.
- アバターロボット "avatar robot" — common for teleop units (ugo, MELTANT, Honda); Ory: 分身ロボット "alter-ego robot".
- 遠隔操作ロボット "(semi-autonomous) teleoperated robot" — Telexistence official label.
- 人型重機 "humanoid heavy machinery" — Jinki Ittai/JR West coinage, recognized mini-category.
- ヒト型/人型ロボット — generic humanoid, leg-agnostic. 半人型ロボット "half-human-type" — rare, literal translations.
- Academic: 移動マニピュレータ, 双腕移動ロボット, 人間共存ロボット (Waseda).
