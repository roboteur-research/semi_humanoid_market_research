# Stretch 3 — Hello Robot  ⚠ BORDERLINE (single-arm)

> **Classification note:** Stretch 3 has ONE arm and no anthropomorphic torso/head — it
> falls outside this study's two-arm semi-humanoid definition and is documented as the
> leading borderline/adjacent concept (per client interest): the minimal, affordable
> mobile manipulator that does a large share of semi-humanoid use cases at a fraction of
> the cost and weight.

| Field | Value |
|---|---|
| Status (2026) | shipping |
| Price | $24,950 |
| Form | telescoping single arm (prismatic) on lift column, diff-drive base, ~24.5 kg |
| Payload | ~2 kg arm |
| Sensing | RealSense D435if head + D405 gripper cam, 2D lidar, IMU |
| Software | open source (ROS 2, Python SDK); huge academic ecosystem; dexterous teleop kit |
| Traction | hundreds of labs; NIH-funded in-home care research; Henry Evans in-home use; imitation-learning demos (Dobb-E, ACT on Stretch) |

Why it matters for this study: Stretch proves a sub-$25k price point and 25 kg mass can
deliver useful mobile manipulation — pressure on 100 kg/$100k dual-arm semi-humanoids to
justify their second arm. Its single-arm limit shows in bimanual tasks (laundry folding,
tray carrying, box handling), which is precisely the gap semi-humanoids fill. [S1][S2]
