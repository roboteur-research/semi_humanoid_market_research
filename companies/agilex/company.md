## Company background
AgileX Robotics ("Mobile the World", 松灵机器人) is China's best-known supplier of research-grade mobile robot chassis: Scout, Tracer, Ranger, Hunter and Bunker platforms are the default bases in countless university and corporate robotics labs worldwide, with published partnerships spanning Carnegie Mellon, Stanford and others [vendor-claimed]. Its Tracer differential base carried Stanford's Mobile ALOHA (Fu/Zhao et al., 2024) — the project that ignited the bimanual mobile-manipulation data-collection wave — giving AgileX the definitive supplier story in this category [third-party].

AgileX productized that lineage as Cobot Magic: a Tracer base with a four-arm leader-follower teleop set (2 leader + 2 follower), cameras and compute, able to run the complete open-source Mobile ALOHA code "with higher configurations and lower costs" [vendor-claimed]. The company monetizes the ecosystem with the $1,999 PiPER 6-DoF arm, LIMO education robots and a broad distributor network (Generation Robots in the EU, RobotShop/robosavvy etc.), all backed by open-source SDKs and manuals on GitHub [vendor/third-party].

## Relevance to the semi-humanoid market
AgileX is the picks-and-shovels vendor of the wheeled-bimanual research boom: it supplies the mobile bases (and now full Cobot Magic rigs) on which VLA datasets are collected worldwide. Any EU semi-humanoid entrant will find AgileX hardware entrenched in labs (including European ones via distributors) at prices no Western maker matches — as a threat it is indirect, but as an ecosystem force it shapes expectations for cost and openness.
